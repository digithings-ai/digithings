# digithings vault — seed overview

Static vault seed for `clients/digithings/`. Used when digichat sends
`X-Digi-Vault-Prefix: clients/digithings` (or when searching the whole vault
in local Profile A dogfood).

digisearch and digivault are the retrieval tools for digithings.ai/chat.
