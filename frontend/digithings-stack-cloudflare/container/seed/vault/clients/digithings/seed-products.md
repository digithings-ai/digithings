# digithings product glossary

| Product | What it does |
|---|---|
| digichat | Chat UI + BFF; Sources / activity for tools |
| digigraph | LangGraph orchestration brain |
| digikey | Auth plane (JWT, API keys, BFF) |
| digisearch | RAG — chunks + embeddings in named indexes |
| digivault | Markdown vault + note search |
| digillm | LiteLLM proxy with caching |

digiquant (backtests), digismith (tracing), and digiclaw (heartbeat) are separate
modules and are **not** inside the Profile A website-chat Container.
