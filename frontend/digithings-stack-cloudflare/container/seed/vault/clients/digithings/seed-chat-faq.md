# digithings.ai/chat FAQ

## What is this?

A documentation assistant for digithings — client #0 dogfood of the self-hosted
stack.

## Why Sources?

Answers are grounded in digisearch (`digithings_docs`) and digivault notes under
`clients/digithings/`.

## OCC vs digithings chat

`/chat/occ` is a different tenant with the OCC help corpus. Default
digithings.ai/chat uses digithings product docs.
