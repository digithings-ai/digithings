# docs

Index of the digithings repository docs. Runtime behaviour lives in code and in each module's `ARCHITECTURE.md`. This directory is reference material.

Paperclip is the live work tracker. Do not add new task lists here.

| File | What it is |

| [VISION.md](VISION.md) | Product direction |
| [DEPLOYMENT.md](DEPLOYMENT.md) | How a release is deployed |
