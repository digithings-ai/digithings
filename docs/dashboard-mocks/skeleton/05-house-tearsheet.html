Method

The house paper book, valued at close from the finalized accounting series. Window 2026-09-08 to 2026-09-30, 17 NAV points. Paper, in-sample: the book has run for 17 trading days.

Day return is an em dash across a NAV seam or a calendar gap over 4 days. Alpha and information ratio need at least 20 overlapping daily pairs; this window has 16. Excess is the book return minus SPY close return over the same dates. It is not alpha.

Closed book events are included in NAV. They are listed on Ledger. This report does not blend in a strategy backtest.
