Cloudflare stack — how it is wired

Pages serves the static sites. Workers own the hostnames and decide who passes. Containers run the stateful services. KV, R2 and D1 hold everything that must persist.

Why this matters. There is no second Worker, container or namespace. A defect in tenant resolution is therefore not contained to one surface — which is exactly what happened when the MCP identity key was not forwarded: only the house tenant could mint a token, and OCC quietly lost its two search servers while helpdesk, on a static key, kept working.
