## Binding behavior
1. Entitlement gate in `dispatch.py`: `plan_tier ∈ {custom, enterprise}` AND
   `subscription_status = active` AND BYOK present-and-unsealable — else job row
   `skipped` with reason (`no_credentials` / `not_entitled`), visible, never silent.
2. Idempotent claim: `job_runs` insert with `idempotency_key = (workspace_id, 'overlay_daily', run_date)`;
   `FOR UPDATE SKIP LOCKED` claim pattern per roadmap P7.
3. **Corpus writes stay tenant-agnostic:** publish-if-missing under `theme:/asset:/segment:` keys;
   a write-time assertion rejects any key containing the workspace/user id (test-pinned).
4. **Private phase is workspace-scoped:** H7–H9 artifacts, ledger chain, book, NAV rows all carry
   the overlay `workspace_id`; grep-audit every writer call in `runner.py`'s path.
5. Budget: accumulate attributed cost per run via WP1 telemetry (`olympus_provider_attempts`);
   crossing `research_budget_usd` ⇒ graceful stop (carry/skip remaining research, still commit
   what's consistent), job row `budget_exhausted`, UI-visible state.
6. BYOK: unseal inside the job only; provider client constructed with the user key; house keys
   NEVER fall back for overlay LLM calls (D9 — test-pinned).
7. Isolation: overlay exception paths never touch house run state or its job rows; overlay failure
   alerting separate. House venue stays `PAPER_INTERNAL` (K4 policy hard-codes it — don't touch).
