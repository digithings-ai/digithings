## Binding behavior
1. Webhook: verify signature; insert `stripe_events(stripe_event_id)` first — duplicate key ⇒
   200 no-op (idempotency); apply the roadmap P4 event→columns mapping; **out-of-order guard**:
   ignore an event whose `created` is older than the last applied event for that subscription.
2. Price→tier map lives in `_shared/tiers.ts` keyed by env price ids:
   Baseline prices ⇒ `baseline`, Custom ⇒ `custom`; `subscription.deleted`/`canceled` ⇒ `free`.
3. After any tier change: update `workspaces` row AND
   `auth.admin.updateUserById(user_id, { app_metadata: { plan_tier } })` for every member of the
   workspace — both or neither (do the auth update last; on failure log + mark row
   `claim_sync_pending=true` column added by this WP's small migration, retried by next webhook).
4. Checkout session: caller's workspace resolved via `workspace_members`; reuse
   `stripe_customer_id` if present; success/cancel URLs from env `NEXT_PUBLIC_APP_URL`.
5. Error contract per roadmap: 401 unauthenticated, 403 wrong workspace, stable JSON codes —
   never a stack trace, never a key in a response.
6. No secret ever committed; functions read Deno env; document `supabase secrets set` commands in
   the functions README.
