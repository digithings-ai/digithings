## Binding behavior
1. UI gating is presentation; **never** rely on it for privacy — RLS already denies the payload.
   A locked panel must render correctly when the query returns nothing (both orders: locked-then-
   empty and empty-then-locked).
2. Flag coupling: when `NEXT_PUBLIC_DASHBOARD_AUTH` is off (pre-cutover), `tierFromSession` returns
   `enterprise` (everything visible — today's operator behavior, test-pinned) so this WP can merge
   before the auth cutover without changing prod.
3. K5's digest builder mirrors this matrix in Python — add a header comment in `entitlements.ts`
   naming `digiquant/src/digiquant/notify/entitlements.py` as the mirror that must stay in sync,
   and vice versa (grep both in review).
4. No new colors/hierarchy: locked states use existing tokens (`--accent`, muted ink); PM-voice
   copy, no exclamation marks.
