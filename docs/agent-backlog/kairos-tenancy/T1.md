## Binding behavior
1. Static export discipline: no `route.ts`, no server components, no runtime env beyond
   `NEXT_PUBLIC_*` (inlined at build). `output:'export'` must still build.
2. Flag off (default) ⇒ zero behavior change (test-pinned: gate renders children, queries use anon
   client). Cutover = flip flag + the anon-policy-drop migration (drafted in T0, shipped in this
   release train by the human coordinating deploy) + owner removes Cloudflare Access from prod.
3. Session-aware queries: `lib/queries.ts` reads the client from context (authed when flag on);
   no query text changes — RLS does the scoping.
4. OAuth providers: Google + GitHub only (D4). Redirect URL = `https://digiquant.io/dashboard/auth/callback/`
   (+ localhost dev) — document the Supabase dashboard config steps in AUTH.md (human performs).
5. Never store tokens outside supabase-js's own storage; no custom cookie code.
