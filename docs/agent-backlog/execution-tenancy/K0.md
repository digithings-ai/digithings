## Interfaces (implement exactly; Pydantic v2, `extra="forbid"`, frozen)
```python
class ExecutionVenue(StrEnum):
    PAPER_INTERNAL = "paper_internal"; ALPACA_PAPER = "alpaca_paper"; IBKR_PAPER = "ibkr_paper"
    ALPACA_LIVE = "alpaca_live"; IBKR_LIVE = "ibkr_live"   # defined, never routable here

class BrokerOrderStatus(StrEnum):  # submitted accepted partially_filled filled canceled rejected expired
class OrderSide(StrEnum): BUY = "buy"; SELL = "sell"
class TimeInForce(StrEnum): DAY = "day"; GTC = "gtc"; OPG = "opg"; IOC = "ioc"

class BrokerOrderRequest(BaseModel):
    client_order_id: str            # = str(order_intent_id) when intent-derived
    symbol: str                     # 1..20 chars, upper
    side: OrderSide
    quantity: Decimal | None        # > 0; XOR with notional (validator)
    notional: Decimal | None        # > 0 dollars
    order_type: str = "market"     # market|limit v1
    limit_price: Decimal | None     # required iff order_type == "limit"
    time_in_force: TimeInForce = TimeInForce.DAY

class BrokerOrderAck(BaseModel):    # external_order_id, status, submitted_at (UTC), raw_sha256
class BrokerFill(BaseModel):        # external_fill_id, symbol, quantity>0, price>0, fee>=0|None, executed_at UTC
class BrokerPosition(BaseModel):    # symbol, quantity (signed Decimal), avg_entry_price, market_value, unrealized_pl
class BrokerAccountSnapshot(BaseModel):  # account_id, equity, cash, buying_power, currency, as_of UTC
```
Protocol additions on `BrokerAdapter`: `get_account()`, `get_positions()`,
`submit_order(req: BrokerOrderRequest) -> BrokerOrderAck`, `get_order(external_order_id)`,
`cancel_order(external_order_id) -> None`, `list_fills(since: datetime) -> list[BrokerFill]`,
plus existing `name`/`connect`/`disconnect`. Migrate stubs to the new `submit_order` signature.

## Rules
- `Decimal` everywhere money/qty appears; UTC-aware datetimes rejected if naive (mirror
  `portfolio_ledger._reject_non_utc`).
- Validators: quantity XOR notional; `limit_price` presence tied to `order_type`; symbol
  uppercased/stripped.
- Forbidden names anywhere in this WP: `place_order`, `execute_trade`, `live_trading` (pre-push
  hook patterns). Nothing routes `*_LIVE` values.
