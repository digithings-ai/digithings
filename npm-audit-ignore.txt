# One advisory identifier per line. The `npm audit` classifier matches against
# the advisory's GHSA id, its URL, or its title, so any of these work:
#   GHSA-aaaa-bbbb-cccc

#
# `#`-prefixed lines (and inline trailing `# …` comments) are ignored.

# Every entry MUST include a justification comment on a neighbouring line:
#   - why the advisory doesn't apply to our usage (e.g. dev-only, unreachable
#     path, no fix available yet), and
#   - when the entry should be re-evaluated (upstream fix version / date).

# ── Accepted risk: next@16.2.4 and the postcss/sharp it bundles (#4396) ──────
#
# All 30 advisories below share one remediation: `next@16.3.5`. We are
# deliberately pinned at 16.2.4 because the bump re-reds three Next builds with
# ~79 pre-existing TypeScript errors (66 dashboard, 8 digichat, 5
# digiquant-web). That upgrade — its acceptance criteria are "0 HIGH/CRITICAL"
# and "this lane goes green" — is tracked as #4396.
#
# postcss 8.4.31 is the copy nested inside next
# (`node_modules/next/node_modules/postcss`); sharp 0.34.5 is next's
# optionalDependency. npm's only offered fix for both is the same `next@16.3.5`,
# so they clear with that upgrade. Forcing them via a root `overrides` entry was
# evaluated and rejected: npm will not apply an override without a full
# lockfile re-resolve (290 unrelated version moves, including downgrades), and
# it would pin sharp 0.35.4 outside next 16.2.4's declared `^0.34.5`.
#
# Re-evaluate when #4396 lands: delete this whole block and let the lane enforce.
