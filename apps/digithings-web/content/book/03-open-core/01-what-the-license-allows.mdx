---
title: What the license allows
order: 1
summary: >-
  MIT for the components, a written policy for what they depend on.
---

The components are published under the MIT license. You can use them
commercially, change them, ship them inside a closed product and never send a
change back. The only condition is that the license notice travels with the
code.

An open license on the project means little if its dependencies carry
conditions the project never examined. The dependencies are held to a written
policy. Permissive licenses are the default. Weak copyleft is accepted only
when the package is used unmodified, and each acceptance is recorded with its
version and the reason. Strong copyleft in anything that ships needs an
explicit decision, and the default answer is to replace the dependency.

The effect is that the license you read at the top of the repository is the
license you actually get, including for the code you did not see.
