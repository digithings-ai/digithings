Most AI platforms ask you to accept their shape whole. digithings takes the
opposite position. It is a set of small modules, each with one job, tied
together by a single hub and a handful of open protocols. You can run all of it,
some of it, or replace any part of it with something you already own, and it
behaves the same way on a laptop as it does in production.

The shape holds one idea at a time: the whole system, then the kinds of module,
how they talk to each other, where the stack runs, and what happens to a single
chat message from the browser to a model and back. It closes with the design
decisions that produced this shape and with what you can build on top of it.

This stays at the level of architecture and reasons. Where you need the
exact interfaces, configuration or commands, each page ends with a link to the
reference document that owns that detail.
