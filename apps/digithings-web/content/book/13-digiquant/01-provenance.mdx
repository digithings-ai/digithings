title: Provenance on every number
order: 1
summary: >-
  What travels with a result so it can be believed later, and why a refused
  estimate carries no number at all.
---

Every backtest result carries a provenance stamp: the engine, the version
that actually loaded, the version the project pins, the first characters of
the lockfile's hash, and whether the returns series behind the chart was
checked. That attachment is what turns a number into evidence. Months later,
an operator can rebuild the same environment and rerun it, or find honestly
that it can no longer be rebuilt, which is itself an answer.

The harder rule concerns refusal. If the engine is not installed in the
process that produced a result, the stamp has no version, and the result is
marked partial with the words "engine unresolved, not citable". The project's
own phrase for it is "withhold, never fabricate". A blank where a number would
be is uncomfortable, and deliberately so. Partial results are labelled
partial, never rounded up into conclusions.
