---
title: "Why there is no plan to sign up for"
order: 3
summary: >-
  You cannot buy a seat on digithings. A managed deployment is a client
  engagement with an owner, not a self-serve tier, and the difference is
  deliberate.
---

It would be easy to add a self-serve tier: run the stack centrally, charge per
seat or per request, and let people skip the self-hosting step entirely. It
would also put someone else back between you and your own infrastructure,
which is the thing the earlier chapters argued against.

There is a version of this that works, and it is managed hosting for a client:
digithings runs the stack on the client's behalf, under a contract, with an
owner to call and a way to walk away with the deployment. That is an
engagement, and the client still owns the outcome.

What there is not is a sign-up page. A tier priced per seat only pays when
self-hosting is inconvenient enough that people pay to avoid it, and building
one would make that inconvenience a reason to exist. Plenty of good companies
run that business honestly. This stack is shaped for a different one.

So the absence of a sign-up tier is not a gap in the roadmap. It is the
conclusion the rest of this book was building toward, priced.
