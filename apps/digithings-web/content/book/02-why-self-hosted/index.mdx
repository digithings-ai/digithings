---
title: Software that lives anywhere
order: 2
summary: >-
  An AI application should not be tied to the machine it first ran on. Build on a laptop, scale in place, move to the cloud without a rewrite.
---

An AI application should not be tied to the machine it first ran on. The model
endpoint, the data store and the number of users will change. The application
should not have to change with them.

digithings is built so the same code runs on a laptop and in a cloud account.
You develop locally, prove the application end to end, then move it when the
work needs more capacity. The migration is a deployment choice, not a rewrite.

This is not an argument against cloud. It is an argument against choosing
infrastructure before you know what the application needs. Open source, open
core and standard protocols keep that choice open. No layer in the stack
decides where the rest of it must live.
