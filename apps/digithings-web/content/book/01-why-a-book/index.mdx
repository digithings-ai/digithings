title: Why this book exists
order: 1
summary: >-
  The docs explain how to run the software. This book explains why owning the infrastructure is worth the work.
---

Most of what gets written about AI infrastructure is written by whoever is
renting it to you. This book is written from the other side of that
relationship: what changes when you run the thing yourself, and why
self-hosting is a position worth choosing rather than an inconvenience to
tolerate until you can afford otherwise.

It is not a tour of digithings' internals — the docs on this site already
cover that, endpoint by endpoint. This is shorter, and argues a position about
infrastructure in general: why it matters, how it scales, and what it costs.
Where it needs an example, it reaches for the nearest one, which happens to be
this project, but the argument is not about digithings.
