---
title: "What it is not"
order: 2
summary: >-
  Not an architecture manual, and not a second home for the API reference.
---

This is not an architecture manual. It does not walk through modules, request
lifecycles, or deployment topology — that material lives in the docs, where a
diagram can be regenerated the day the code changes and a claim can be checked
against a file and a line number. A book that tried to do the same job would
be stale before it shipped.

Nor is it a second home for the API reference, or a place for anything we
cannot stand behind. It is an argument, not a spec: about why self-hosting
matters, how it scales past the first machine, and what it actually costs —
made in prose precisely because that argument does not change every time a
route does.
