---
title: "What it is not"
order: 2
summary: >-
  Not an architecture manual, and not a second home for the API reference.
---

This is not the reference. It names the modules and the seams between them,
and stops where the reference starts: request formats, settings and
deployment topology live in the docs, where a diagram can be regenerated the
day the code changes and a claim can be checked against a file and a line.

Nor is it a place for anything we cannot stand behind. It is an argument, not
a spec: why self-hosting matters, how the stack grows past the first machine,
and what that costs. A chapter says what is built; where something is planned
and not built, it says so.
