An AI model on its own can only write text. To do anything else, search an
index, run a backtest, open a ticket, it needs tools: named functions with
described inputs that it may ask to call. The Model Context Protocol (MCP),
published by Anthropic in 2024 and since adopted by many AI clients, is the
open standard for offering those tools. Each one has a name, a schema for its
inputs and a description a model can read.

MCP is not a module, and you do not run it. It is a layer on the edge of each
module that has something to offer. digigraph, digisearch, digiquant and
digivault each run an MCP server beside their HTTP API, and the digillm library
ships an optional one.

## Two directions

**Out.** Any MCP client can use those servers: Claude Desktop, a code editor,
or a terminal agent you wrote, over a local pipe or across a network. No
digichat and no hub sit in between. When a better client ships next year, it
can search your index the day it ships.

**In.** digigraph is itself an MCP client. An operator lists tool servers, the
team's tracker or someone else's product, and the hub offers their tools to the
model on the next request, with no change to the hub.

The hub reaches its own verticals over a plainer HTTP manifest, because it
treats their results specially: citations, vault notes, backtest results. The
trade is that a new first-party tool needs a change in the hub, while a tool on
an MCP server needs none.

## The gate

Each server the operator adds says which of its tools are allowed and which of
them change something. Allowed read-only tools run unattended. A tool that
changes something stops the turn and shows the exact call in the chat until
whoever is at the keyboard approves or declines it.

```mermaid offered and executed are checked separately, so a model only sees tools it may call
flowchart LR
  SRV[tool server] --> LIST[allow-list]
  LIST --> GATE{may it run?}
  GATE -->|yes| RUN[runs]
  GATE -->|ask| PERSON[a person approves]
  PERSON --> RUN
```

The gate is checked where the tool executes, not only where it is offered, so
a prompt that talks a model into a forbidden tool still fails at the gate.
