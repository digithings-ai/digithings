---
title: What stays the same
order: 1
summary: >-
  Moving from a laptop to a cloud account changes capacity, not contracts.
---

A module can move without becoming a different module. The setting names, the
service boundaries and the protocol at each edge stay fixed. A laptop supplies
a local model runner and an embedded store; a cloud account supplies managed
versions of the same interfaces.

That is why the stack can be adopted one piece at a time. Start with the model
layer, add retrieval, then add a vertical. Each step is a deployment choice,
not a migration project.
