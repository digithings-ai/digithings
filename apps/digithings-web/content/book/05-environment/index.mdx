An AI application is more than a model call. It needs a way to reach models,
route work between them, retrieve context, remember what happened, identify
who is asking, expose tools, show an interface and explain the result. Most
projects spend their first months rebuilding that surrounding environment.

digithings is that environment. It is built from small modules with one job
each, tied together by open protocols. Model access, orchestration, retrieval,
memory, identity, chat, data, tracing and tool discovery are separate pieces,
so you can run one, a few, or all of them.

The stack is open source and open core. You can read the code, replace a module
and keep the parts that work. Nothing at the boundary is proprietary, and no
module requires the others to be bought as a bundle.

Capability and cost move together. A single person can run the core on a
laptop. A research team can add retrieval and a vertical service. An
organisation can add identity, tracing, data and more hardware without
changing the contracts underneath. The same environment scales from a
workstation to a fleet, and the bill follows the parts you actually run.
