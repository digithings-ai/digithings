Left alone, every service grows its own model client. Each picks a favourite
vendor, retries in its own way and fails in its own way. A year later,
switching models means touching every service, and nobody can say what a
model call costs. digillm exists so that never happens: one library, used by
every service, with no preference for any vendor.

With a shared layer, changing models is a configuration choice. digillm
speaks the OpenAI chat format, which most providers, local runners such as
Ollama and routing proxies such as LiteLLM accept, so they all look the same
to the calling code. Trying a new model changes where the traffic goes, not
how the code asks for it. The catch is that a feature only one
provider offers waits until the format can carry it.

## How it works

digillm is a library first. It ships inside the services that use it
and defines the shapes every model call shares: the request, the tool call,
the tool definition and structured answers checked against a schema. On top
of those shapes it adds what every caller needs and nobody wants to write
twice: retries, timeouts, usage accounting and optional tracing.

```mermaid any service reaches any model through one layer; the provider is a setting
flowchart LR
  SVC[any service] --> LIB[digillm]
  LIB --> LOCAL[local model]
  LIB --> PROXY[routing proxy]
  PROXY --> HOSTED[hosted models]
```

The library has two hard dependencies, the OpenAI client and Pydantic, and
never imports a web framework. So the same code can live inside an
orchestration hub, a retrieval service and a research pipeline without
dragging their worlds along.

## Where it fits

The hub, retrieval and research all make their model calls through it.
Because the shapes are shared, a structured answer produced in one service can
be read in another without translation. When tracing is configured, usage flows into the trail;
when it is not, the hooks cost nothing.

A library has no home of its own. In the local stack it points at LiteLLM,
which routes each model name to Ollama on the same machine or to a hosted
provider. Where models run stays an operator decision, never a code change.
