---
title: Choosing a starting set
order: 1
summary: >-
  Four applications, four small module sets. Add capability only when the work asks for it.
---

| Application | Start with | Add when needed |
| --- | --- | --- |
| Financial research | digiquant, digigraph, digichat | digisearch, digitrace |
| Voice | digivoice | digichat, digivault |
| Retrieval | digisearch, digivault | digillm, digitrace |
| Agents | digigraph, your tools as MCP servers | digichat, digitrace, digivault |

The list is a starting point, not a product tier. Every application can run on
one machine, and every module can be replaced without rewriting the others.
